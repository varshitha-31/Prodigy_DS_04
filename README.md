# Task-04: Sentiment Analysis and Visualization

## 📌 Overview
This project was completed as part of the **Prodigy InfoTech Data Science Internship**.

The objective of this task is to analyze and visualize sentiment patterns in social media data to understand public opinion and attitudes towards different brands or topics.

---

## 🎯 Objective

- Perform sentiment analysis on social media data.
- Explore sentiment distribution.
- Visualize public opinion using different charts.
- Identify the most discussed brands/entities.
- Understand sentiment trends across different entities.

---

## 📂 Dataset

Dataset Used: Twitter Entity Sentiment Analysis Dataset

The dataset contains:
- Sentiment Labels
- Entity/Brand Names
- Tweet Text

---

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📊 Exploratory Data Analysis

The following visualizations were created:

- Sentiment Distribution
- Top 10 Most Mentioned Brands
- Sentiment by Top 10 Brands
- Confusion Matrix
- Data Cleaning and Preprocessing

---

## 🚀 Project Workflow

1. Import Libraries
2. Load Dataset
3. Explore Dataset
4. Handle Missing Values
5. Data Cleaning
6. Perform Sentiment Analysis
7. Create Visualizations
8. Interpret Results

---

## 📈 Key Insights

- Negative sentiment was the most common sentiment in the dataset.
- Several brands received mixed public opinions.
- Frequently mentioned brands generated both positive and negative discussions.
- Data visualization helped identify sentiment trends effectively.
